## Find the implementation

This catalogue scans `Components/Sources`, `Components/Converter` and `Components/Renderer` at the recorded commit. It includes classes whose names match their module filenames. It records explicitly declared properties; inherited and dynamically assigned properties may also exist.

This is an implementation directory, not a complete list of valid converter arguments or a compatibility matrix. Open the linked constructor to check arguments and inspect the properties it reads from its upstream source. Availability on a particular receiver still depends on its installed image and packages.

Read [the data-flow introduction](../../data-flow/) before joining classes. A source class appearing in this catalogue does not mean a source of that name is registered in every Python screen.
