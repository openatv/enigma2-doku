Die ersten drei Zeilen gehören zu jedem Bereich: Stilpaket, Bereich und OSD-Auflösung. Beim Scrollen können sie aus dem sichtbaren Ausschnitt wandern. „Bereich“ filtert die Optionen in Farben, Layout, Infobar und Kanalliste. Ein Bereichswechsel verwirft deine noch nicht gespeicherten Änderungen nicht.

| Bedienung | Was passiert |
| --- | --- |
| Pfeile hoch und runter | Eine Einstellung auswählen. |
| Pfeile links und rechts | Zwischen den angebotenen Werten wechseln. Textfelder mit der normalen OpenATV-Eingabe bearbeiten. |
| Grün   Speichern | Alle Änderungen speichern und Umbra neu anwenden, auch aus anderen Bereichen. |
| Rot oder Exit   Abbrechen | Noch nicht gespeicherte Änderungen in allen Bereichen verwerfen. |
| Gelb   Paketwerte | Nach Rückfrage alle individuellen Stilabweichungen zurücksetzen. Erst Grün wendet den neuen Stand an. |
| Blau   Stil speichern | Die aktuell wirksame Gestaltung als eigenes Paket exportieren. Dieser Export bleibt auch erhalten, wenn du danach abbrichst. |

## Ein sicherer erster Versuch

1. Wähle das Paket Umbra Graphit und lasse die Auflösung zunächst unverändert.

2. Öffne den Bereich Farben und wähle eine andere Fortschrittsfarbe.

3. Drücke Grün und warte, bis „Umbra wird angewendet“ beendet ist.

4. Öffne Infobar und Senderliste. Kehre zum Plugin zurück, um weiter anzupassen.

Live-Neuladen: Auf einer passenden OpenATV-Basis ist normalerweise kein GUI-Neustart nötig. Die Anwendung kann auf der Box deutlich länger als einige Sekunden dauern. Nicht mehrfach speichern. Fehlt die API oder schlägt das Neuladen fehl, fragt Umbra nach einem GUI-Neustart.
