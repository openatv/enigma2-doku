| Option und Auswahl | Sichtbare Wirkung |
| --- | --- |
| Zeilen<br />Standard · Kompakt · Erweitert · Galerie · Spalten | Standard zeigt Sender und aktuelle Sendung. Kompakt benötigt weniger Höhe. Erweitert bietet zusätzliche Angaben. Galerie/Spalten gehören zu den entsprechenden Ansichten. |
| Picons<br />Ein · Aus | Zeigt verfügbare Senderlogos. Umbra lädt keine fehlenden Picons herunter. |
| Kanalnummern<br />Ein · Aus | Zeigt die Kanalnummer an. |
| Empfangsart<br />Ein · Aus | Kennzeichnet die Empfangsart mit dem nativen Symbol. |
| Verschlüsselung<br />Ein · Aus | Zeigt das native Verschlüsselungssymbol. Dies ändert nicht die Entschlüsselung. |
| Picon-Seitenverhältnis<br />XPicon / ZZZPicon · ZZPicon · ZPicon | Passt den vorgesehenen Platz an das Format deines Picon-Satzes an. Die Auswahl lädt keinen neuen Satz. |

Die Höhe der Liste wird auf ganze Zeilen begrenzt. Wie viele Sender sichtbar sind, hängt von Ansicht, Zeilentyp und Auflösung ab. Größere Schrift erzeugt nicht automatisch größere Zeilen.
