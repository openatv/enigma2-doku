---
title: "Fernbedienungstyp, Code und Tastenbelegung"
---

Diese drei Einstellungen lösen unterschiedliche Aufgaben:

| Einstellung | Wofür sie zuständig ist |
| --- | --- |
| Fernbedienungstyp unter Eingabegeräte | Passenden vom Empfänger unterstützten Fernbedienungstyp wählen. |
| Fernbedienungscode | Bei unterstützter Hardware Code beziehungsweise Codefamilie von Handgerät und Empfänger aufeinander abstimmen; kann auch zur Trennung mehrerer Boxen dienen. |
| Keymap / Hotkey | Einer bereits erkannten Taste eine Funktion zuordnen. Ändert nicht den vom Handgerät gesendeten IR-Code. |

**Menü → Einstellungen → Bedienung / Oberfläche → Fernbedienungscode** erscheint nur bei entsprechender Hardwareunterstützung. Die angebotenen Codes und das Umstellen des Handgeräts sind herstellerabhängig. Deshalb enthält die gemeinsame Anleitung keine vermeintlich universelle Tastenkombination.

Vor einer Änderung die passende Herstelleranleitung für das Handgerät lesen, bisherige Auswahl notieren und einen zweiten Bedienweg prüfen. Danach Empfänger und Handgerät auf den zueinander passenden Code einstellen und die angebotene Test-/Bestätigungsfunktion verwenden. Ein Dialog für Fernbedienungstyp kann einen zeitlich begrenzten Rückfall anbieten; darauf nur vertrauen, wenn der konkrete Dialog ihn ausdrücklich zeigt. Eine externe Fernbedienung wird durch den GUI-Schalter nicht automatisch umprogrammiert.

Bei zwei Boxen im selben Raum müssen beide Kombinationen getrennte Codes tatsächlich unterstützen. Bluetooth-/Funkkopplung, HDMI-CEC und IR-Codes sind verschiedene Übertragungswege. Den Fernseher über CEC steuert der [HDMI-CEC-Bereich](../../bild-ton/hdmi-cec/).

Reagiert die Box gar nicht mehr auf IR, zuerst Code/Typ prüfen. Reagiert sie auf die Taste, führt aber die falsche Funktion aus, [Hotkeys und Fernbedienungseinstellungen](../../erste-schritte/farbtasten-langdruck/) prüfen. Ein Wechsel des Skins behebt keinen falschen IR-Code.

Dieser bedingte Menüpunkt wird modellneutral erklärt. Ein Codewechsel wurde auf der Testbox nicht ausgeführt.
