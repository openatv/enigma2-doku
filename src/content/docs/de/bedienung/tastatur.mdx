**Menü → Einstellungen → Bedienung / Oberfläche → Tastatur** legt die Belegung einer angeschlossenen Tastatur fest. **QWERTZ** und **QWERTY** unterscheiden beispielsweise Y und Z sowie viele Sonderzeichen. Das Layout soll zur physischen Tastatur passen, nicht zwangsläufig zur Menüsprache.

1. Tastatur anschließen und prüfen, ob sie unter [Eingabegeräte](../eingabegeraete/) erkannt wird.
2. Das passende angebotene Layout auswählen und Grün/Speichern drücken.
3. Bei einem Wechsel lädt der Dialog das Layout zum Test und fragt, ob die Tastatur funktioniert. Ohne rechtzeitige Bestätigung fällt dieser Test nach 30 Sekunden zurück.
4. In einem geeigneten Textfeld Y/Z, Umlaute, `@`, `/`, `:`, `-` und Ziffern prüfen. Keine Passwörter für einen sichtbaren Test eintippen.

Die Auswahl ist als [Keyboard-Referenz](../../einstellungen/referenz/keyboard/) bereits vorhanden. Das auf einem Bild angezeigte Standardlayout kann mit der aktiven Sprache variieren; eine tatsächlich angeschlossene Tastatur bestimmt, was du wählen solltest.

## Bildschirmtastatur und Fernbedienung

Textfelder bieten je nach Dialog eine Bildschirmtastatur, häufig über die eingeblendete **TEXT**-/Tastatursymbol-Aktion. Die Farbtasten, Umschalttaste und verfügbaren Zeichen stehen im jeweiligen Bildschirm. Manche Felder erlauben Mehrfachdruck auf Zifferntasten, ähnlich früheren Mobiltelefonen. In einem Zahlen-/IP-Feld gelten andere Regeln als in einem Dateinamenfeld.

Cursorposition, Löschen und Einfügen zuerst in einem unverfänglichen Feld ausprobieren. Bei langem Text steuert **Systemeinstellungen → Scrollposition eingeben** den sichtbaren Ausschnitt. Tastenwiederholung wird dagegen beim [Eingabegerät](../eingabegeraete/) eingestellt.

Das externe Layout verändert weder die Bedienaktionen aller Plugins noch automatisch das Layout jeder Bildschirmtastatur. Eine Schrift ohne passende Zeichen wird über Skin/Ersatzschrift behandelt, nicht durch Tauschen von QWERTY und QWERTZ.
