Die **Senderliste**, auch **Kanalliste** genannt, zeigt Sender und Programminformationen. Du kannst ihre Darstellung anpassen, ohne ein neues Senderlistenpaket zu installieren. Diese Seite zeigt die Möglichkeiten mit MetrixHD; andere Skins können andere Vorlagen mitbringen.

## Die Einstellungen mit MENU öffnen

1. Öffne die Senderliste, üblicherweise mit Pfeil hoch oder runter. Eine abweichende Tastenbelegung kann einen anderen Aufruf verwenden.
2. Drücke in der geöffneten Liste <kbd>MENU</kbd>. Das **Kontextmenü der Senderliste** erscheint.
3. Wähle **Einstellungen**. Im geprüften Stand öffnet auch ein zweiter Druck auf <kbd>MENU</kbd> direkt diese Einstellungen.
4. Ändere die gewünschte Option und wähle **Speichern**. Die Senderliste wird aktualisiert. **Abbrechen** verwirft die Änderungen dieses Einstellungsdialogs.

Der reguläre Menüweg ist **Menü → Einstellungen → Bedienung / Oberfläche → Senderliste**.

## Was macht das Kontextmenü?

| Aktion | Verwendung |
| --- | --- |
| Einstellungen | Aussehen und Verhalten der Senderliste ändern |
| Als Startsender auswählen | Festlegen, welcher Sender beim Start verwendet werden soll |
| Sender zu Bouquet hinzufügen | Den markierten Sender in eine Favoritenliste aufnehmen |
| Zum aktuellen Sender springen | Die Markierung zur laufenden Auswahl zurückführen |
| Eintrag umbenennen | Den angezeigten Namen bearbeiten |
| Eintrag entfernen | Einen Eintrag aus der aktuellen Liste entfernen; vor Bestätigung auf die betroffene Liste achten |
| Verschiebemodus aktivieren | Die Reihenfolge der Einträge bearbeiten; anschließend den Modus wieder verlassen |
| Marker einfügen | Eine sichtbare Trennzeile in einem Bouquet anlegen |
| Bouquetbearbeitung aktivieren | Die angebotenen Bearbeitungsfunktionen für ein Bouquet verwenden |
| Alternativen hinzufügen | Ersatzdienste für einen Sender zusammenstellen |
| Senderlisten aktualisieren | Senderdaten erneut laden, beispielsweise nach einer externen Bearbeitung |

Jugendschutz, Informationen und zusätzliche Plugin-Aktionen erscheinen abhängig von Situation, Einstellungsumfang und installierten Erweiterungen. Ein Menü in der Bouquetübersicht bietet andere Aktionen als eines auf einem einzelnen Sender. Für einen anderen **Stil** öffnest du **Einstellungen**; die Bearbeitungsaktionen ändern dagegen die Senderlisten.

## Bildschirm und Liste getrennt auswählen

Die Option **Senderliste / Bildschirm** legt die Aufteilung des ganzen Fensters fest. Die Namen der neuen Vorlagen können auch bei deutscher Oberfläche englisch angezeigt werden.

| Bildschirm | Aufteilung |
| --- | --- |
| Alter Modus / Legacy mode | Klassische Senderliste; MetrixHD bietet dafür vier eigene Varianten |
| List and event details | Senderliste mit ausführlichen Informationen zur markierten Sendung |
| List and live TV | Senderliste mit einem eingebetteten Fernsehfenster |
| Full screen | Die Liste nutzt die breite Bildschirmfläche |

<Capture id="channel-settings" language="de" alt="Senderlisten-Einstellungen mit Senderliste / Bildschirm auf Alter Modus" caption="Alter Modus aktiviert die klassische Darstellung. Die MetrixHD-Variante dazu stellst du in MyMetrixLite ein." />

Bei einem neuen Bildschirm erscheint zusätzlich **Senderliste / Liste**. Damit wählst du die Darstellung der einzelnen Einträge:

| Liste | Wann sie hilft |
| --- | --- |
| Single-line list | Kompakte Liste mit vielen Sendern gleichzeitig |
| Picture list with remaining time | Bilder und verbleibende Laufzeit der aktuellen Sendung |
| Picture list with percentage | Bilder und prozentualer Fortschritt der aktuellen Sendung |
| Programme columns | Mehrere Programminformationen in Spalten vergleichen |
| Picture grid | Sender als Karten in einem Bilderraster überblicken |

<Capture id="channel-settings-new" language="de" alt="Neue Senderlisten-Einstellungen mit getrennter Auswahl von Bildschirm und Liste" caption="Die drei neuen Bildschirmaufteilungen lassen sich jeweils mit fünf Listenstilen kombinieren: insgesamt 15 Varianten." />

Weitere Optionen betreffen beispielsweise Sendernummern, Picons, Dienst- und Verschlüsselungssymbole, Timer- oder Aufnahmemarkierungen und das Bildseitenverhältnis der Picons. Die sichtbaren Felder hängen vom gewählten Modus ab. Bedeutung und Konfigurationsschlüssel stehen in der [Senderlisten-Referenz](../../einstellungen/referenz/channelselection/).

## Die vier klassischen MetrixHD-Varianten

Wähle zuerst **Alter Modus** in den Senderlisten-Einstellungen. Öffne dann **Menü → Erweiterungen → MyMetrixLite → Sonstige Einstellungen** und scrolle zur Option **Senderliste-Stil**. Die vier Varianten kombinieren die Ausrichtung links oder rechts mit einem großen Picon oder mehreren folgenden Sendungen. Speichere und wähle im MyMetrixLite-Hauptfenster **Änderungen anwenden**.

Bei den neuen Bildschirmstilen erfolgt die Vorlagenwahl in der Senderliste selbst. Deshalb ist die klassische Auswahl in MyMetrixLite abhängig vom gewählten Modus. [Weitere MetrixHD-Optionen](../../skins/metrixhd/sonstiges/).

## Galerie: alle 19 Varianten

Öffne die gewünschte Gruppe, um die vier klassischen Ansichten oder alle fünf Listenstile eines neuen Bildschirms zu vergleichen. Ein Klick auf ein Bild öffnet die Originalaufnahme. Alle Bilder stammen aus der laufenden Enigma2-Oberfläche; die Wiedergabe war gestoppt und der Hintergrund ist das Bootlogo. Auch das TV-Fenster zeigt deshalb kein laufendes Programm. EPG-Texte und vorhandene Programmbilder können weiterhin aus gespeicherten Daten erscheinen. Ihre Sprache stammt vom Sender bzw. Datenanbieter und folgt nicht automatisch der Menüsprache.

## Bilder, Picons und EPG verstehen

**Picons** sind Senderlogos. **Programmbilder** sind Bilder zu einer Sendung und benötigen eine passende Datenquelle oder Erweiterung. Eine Bildervorlage erzeugt solche Daten nicht selbst. Fehlende Bilder bedeuten deshalb nicht automatisch einen defekten Skin; je nach Vorlage kann ein Picon als Ersatz erscheinen.

Fehlen Titel, Zeiten oder Fortschrittswerte, prüfe den [EPG](../../epg/grundlagen/). Fehlen ganze Sender, prüfe [Senderlisten und Empfang](../senderlisten/). Ist die Liste zu klein oder überladen, beginne mit **Single-line list** und passe danach [Schriften und Auflösung](../../skins/metrixhd/aufloesung/) an.

Geprüft mit OpenATV 8.0 und MetrixHD in HD. Die Auswahl wird aus den installierten Skinvorlagen gebildet; ältere Image- oder Skinstände können weniger Möglichkeiten anbieten.
