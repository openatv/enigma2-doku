**Set up the path from your OpenATV receiver to the display and speakers.** These chapters apply across models. Available entries depend on connectors, drivers, installed extensions and setup level. Expert mode cannot add a hardware capability that is absent.

## Where to start

1. [Choose the connection path](./anschliessen/): direct TV, AVR, soundbar or optical output.
2. [Establish a stable video output](./video/), then consider [automatic resolution](./autoresolution/).
3. [Understand PCM, downmix and passthrough](./audio-grundlagen/) and configure [audio options](./audio-optionen/).
4. Check [audio tracks and language](./tonspuren/), [volume](./lautstaerke/) and [lip sync](./lipsync/).
5. Then configure [HDMI-CEC](./hdmi-cec/) for power, input selection and remote control.

## Find the right menu

| Task | Menu / chapter |
| --- | --- |
| Resolution, refresh rate, aspect ratio | Setup → Video → [Video Settings](./video/) |
| HDR, HDMI colour space and depth | [HDMI and HDR](./hdmi-hdr/), complete [video reference](./video-optionen/) |
| Cropped menus, sharpness and contrast | Setup → Video → [OSD Calibration / Video enhancement](./bildanpassung/) |
| Downmix, audio output and delay | Setup → Audio → [Audio Settings](./audio-optionen/) |
| Per-service track, audio description | [AUDIO button and automatic language selection](./tonspuren/) |
| Per-service volume | Setup → Audio → [Volume Adjust Settings](./lautstaerke/) |
| Control TV/AVR together | Setup → System → [HDMI-CEC Settings](./hdmi-cec/) |
| Look up individual CEC fields | [All 29 CEC settings and address selection](./cec-optionen/) |
| Power issues and CEC traffic | [CEC logs](./cec-logs/) |
| Black picture, silence or dropouts | [Troubleshooting](./probleme/) |

“AVR” means the home-cinema audio/video receiver or amplifier. The OpenATV receiver is the source device. **HDMI audio, ARC/eARC and CEC serve different purposes:** audio transport, return audio and control messages. A working power command does not prove that multichannel audio works.

Native example images show accessible menus. They do not establish compatibility with every audio format, HDR mode or TV/AVR combination. [Sources and verification scope](./quellen/).
