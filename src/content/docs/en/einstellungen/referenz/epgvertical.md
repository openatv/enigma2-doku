This reference contains the help text provided by openATV. The open dialog and selected options determine which entries are visible.

## Where do I find it?

**Main Menu → Setup → EPG → VerticalEPG Settings**

Search also matches technical keys. [Back to the directory](../../)

<h2 id="option-90ee6bc699b4">Start mode</h2>

<p>Here can set the EPG will alway open at the current channel, the first channel or one of both with primetime. If no primetime selected, the current time is used.</p>

<details>
<summary>Reference & notes</summary>

`config.epgselection.vertical_startmode`

Setup level: Expert.

</details>

<h2 id="option-7b350f3afe51">Picture in EPG</h2>

<details>
<summary>Reference & notes</summary>

Setup level: Expert.

</details>
