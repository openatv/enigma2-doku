This reference contains the help text provided by openATV. The open dialog and selected options determine which entries are visible.

## Where do I find it?

The direct menu location has not yet been mapped in this first edition. Look for **ChannelEPG Settings**.

Search also matches technical keys. [Back to the directory](../../)

<h2 id="option-7dd4c9d62074">Sort list by</h2>

<p>You can have the list sorted by time or alphanumerical.</p>

<details>
<summary>Reference & notes</summary>

`config.epgselection.sort`

Setup level: Expert.

</details>

<h2 id="option-29522d966c3f">Number of rows</h2>

<p>Configure the number of rows shown.</p>

<details>
<summary>Reference & notes</summary>

`config.epgselection.enhanced_itemsperpage`

Setup level: Expert.

</details>

<h2 id="option-6e803865b09f">Event font size</h2>

<p>Configure the font size relative to skin size, so 1 increases by 1 point size, and -1 decreases by 1 point size.</p>

<details>
<summary>Reference & notes</summary>

`config.epgselection.enhanced_eventfs`

Setup level: Expert.

</details>
