This reference contains the help text provided by openATV. The open dialog and selected options determine which entries are visible.

## Where do I find it?

**Main Menu → Setup → Audio → Auto Language Settings**

Search also matches technical keys. [Back to the directory](../../)

<h2 id="option-c6fe9ce3582b">Allow subtitle language to equal audio language</h2>

<p>Usually when the subtitle language is the same as the audio language, the subtitles will not be used. Enable this option to allow these subtitles to be used.</p>

<details>
<summary>Reference & notes</summary>

`config.autolanguage.equal_languages`

Setup level: Intermediate.

Visibility depends on other options or the dialog.

</details>
