This reference contains the help text provided by openATV. The open dialog and selected options determine which entries are visible.

## Where do I find it?

The direct menu location has not yet been mapped in this first edition. Look for **Picon Settings**.

Search also matches technical keys. [Back to the directory](../../)

<h2 id="option-e398b00d6cfe">Picon search mode</h2>

<p>Select the search mode to find picons. &#x27;Single-path mode&#x27; uses one path for all picons. &#x27;Multi-path mode&#x27; allows multiple picon paths to be used for different use cases.</p>

<details>
<summary>Reference & notes</summary>

`config.picon.mode`

Setup level: Simple.

</details>
