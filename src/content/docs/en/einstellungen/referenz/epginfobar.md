This reference contains the help text provided by openATV. The open dialog and selected options determine which entries are visible.

## Where do I find it?

**Main Menu → Setup → EPG → InfoBar EPG Settings**

Search also matches technical keys. [Back to the directory](../../)

<h2 id="option-27135d78fa89">View mode</h2>

<p>This option allows you to set the layout view (Text or Graphics).</p>

<details>
<summary>Reference & notes</summary>

`config.epgselection.infobar_type_mode`

Setup level: Expert.

</details>

<h2 id="option-4b455f8fa9d7">Channel preview mode</h2>

<p>Select &#x27;Yes&#x27; to enable preview of channels while in the EPG list.</p>

<details>
<summary>Reference & notes</summary>

Setup level: Expert.

</details>

<h2 id="option-5043add91211">Skip empty services</h2>
