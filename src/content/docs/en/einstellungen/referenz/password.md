This reference contains the help text provided by openATV. The open dialog and selected options determine which entries are visible.

## Where do I find it?

**Main Menu → Setup → Network → Password Settings**

Search also matches technical keys. [Back to the directory](../../)

<h2 id="option-a07d5fe50799">New password</h2>

<p>Setting a password is strongly advised if your receiver is open to the Internet. You must set a password in order to be able to use network services like FTP, Telnet or SSH.</p>

<details>
<summary>Reference & notes</summary>

`config.network.password`

Setup level: Simple.

</details>
