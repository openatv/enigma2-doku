This reference contains the help text provided by openATV. The open dialog and selected options determine which entries are visible.

## Where do I find it?

**Main Menu → Plugin Browser**

Search also matches technical keys. [Back to the directory](../../)

<h2 id="option-4e45f1f35172">Plugin Browser layout</h2>

<p>Select the layout of the installed plugins in the Plugin Browser screen. NOTE: The change is not immediate but will be seen when Plugin Browser is restarted!</p>

<details>
<summary>Reference & notes</summary>

`config.usage.pluginListLayout`

Setup level: Simple.

</details>

<h2 id="option-38c787707ff0">Sort Plugin Browser entries</h2>

<p>Select the sort order of the Plugin Browser menu entries. User defined also allows the plugin entries to be hidden.</p>

<details>
<summary>Reference & notes</summary>

Setup level: Simple.

</details>
