This reference contains the help text provided by OpenATV. The open dialog and selected options determine which entries are visible.

## Where do I find it?

**Main Menu → Setup → Usage & GUI → Configure front panel LEDs**

Search also matches technical keys. [Back to the directory](../../)

<h2 id="option-d7dc7c659f9e">LED Running color</h2>

<p>Select the color of the front panel power LED when the receiver is Running. This option also allows the LED to be deactivated/turned off.</p>

<details>
<summary>Reference & notes</summary>

`config.fp.led.default_color`

Setup level: Intermediate.

</details>
