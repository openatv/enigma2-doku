## The three storage tools

<Capture id="sys-storage-menu" language="en" alt="Storage Devices menu with Device Manager, Swap and Flash Expander" caption="Device Manager, Swap and Flash Expander serve different purposes." />

**Device Manager** handles drives, mounts and file systems. **Swap** helps when RAM is under pressure. **Flash Expander** provides more space for part of the installed system. All three still require an appropriate [backup strategy](../wartung/backup-restore/).

A [NAS recording destination](../speicher/nas-aufnahmen/) is connected through network shares. A network mount is unsuitable as a replacement for an always-available local system or swap drive.

## Missing menu items

If necessary, select **Expert** under **Usage & GUI → Customize → Setup mode**. The source menu assigns level 1 to Script Manager and level 2 to Swap and Flash Expander. HDMI-CEC and RF output also require device support. Check for [hidden menu entries](../erste-schritte/menue-anpassen/) too.

**Customize** under Usage & GUI is a separate section. It includes startup behaviour, streaming and operating preferences; use its [existing guide](../bedienung/systemanpassen/) for these settings.
