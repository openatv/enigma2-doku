This part of the OpenATV handbook is for developers. It starts with **skinning**: how Python screens, XML layouts and native Enigma2 widgets produce the interface on a receiver.

All developer chapters are written in English and appear unchanged in both handbook editions. The global search includes them in both editions. ## Scope of the developer units

The examples use deliberately small, independent screens. They teach the shared Enigma2 skin engine without depending on a particular receiver model, channel, recording or network configuration.

The advanced unit adds nine native examples for InfoBar, ChannelSelection, panels and icon fonts. ChoiceBox and other specialised screen recipes can follow in later units. A searchable name in the source index is not a claim that its complete API is taught here.
