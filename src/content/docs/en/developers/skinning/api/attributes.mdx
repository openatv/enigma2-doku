## Search attributes

This list contains the **99 current or reserved handlers** from the pinned `skin.py`. The other **26 deprecated or compatibility names** have moved to the [migration reference](../deprecated/). For a name used elsewhere in a skin, start with the [skin dictionary](../dictionary/): it also indexes XML structure, list templates and Python component attributes.

Each entry gives its purpose, value syntax, supported native classes, an XML example where the handler has an established authoring use, and limitations. Examples are source-checked fragments for an existing screen; named widgets and sources must already exist. Reserved no-op handlers and raw native setters without established XML conversion are explicitly identified instead of supplying a misleading example.

Omission and invalid input are different: a parser fallback is not the default appearance of every widget. The active window style, component and renderer may supply or override a value. The [foundation examples](../../) have actual receiver captures; the new reference snippets do not claim a receiver rendering test.

Looking for the value column moving inward when a scrollbar appears? See [scrollbarMode="showOnDemandShrink"](../../recipes/scrollbar/). For text underlining, see the [label and template examples](../../recipes/underline/).
