| Recording marking (Aufnahme-Markierung) | Off: no corresponding mark. Icon: native recording symbol. Text colour: indicates an active recording using the dedicated text colour. |

## Recognise active recordings

For text marking, use **Colours → Recording text (RGB)**. Umbra's default is light gold. The setting applies to selected and unselected entries. Red buttons and error messages do not need to be recoloured.

## Displaying a timer is not recording control

Starting a recording, editing a timer, series rules and resolving conflicts remain OpenATV or recording-plugin functions. The skin only controls how the information is displayed. See [recording and zap timers](../../../timer/aufnahmen/) and [AutoTimer](../../../addons/autotimer/).
