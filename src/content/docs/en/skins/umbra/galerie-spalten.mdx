These original HD examples show a TV bouquet. Other list types may use different layouts. The gallery has five columns and three rows in the illustrated HD layout; the columns view has five tall columns with description, following events and primetime.

Umbra pairs Gallery automatically with Gallery rows and Columns with Columns rows. When a normal list view is selected, a saved gallery/columns row choice falls back to the standard row so that the geometry fits.

Current density profiles provide **5×3 tiles in HD, 6×3 in FHD and 7×4 in WQHD** at standard text size. The columns view provides **5 / 6 / 7 columns** respectively. These are layout capacities, not a promise that every bouquet contains that many entries or that every programme has artwork.

The native EPG's separate “entries per page” preference remains relevant to EPG screens. Changing the OSD resolution does not override a user-selected EPG row count. See [resolution and density](../aufloesung/) for the complete comparison.
