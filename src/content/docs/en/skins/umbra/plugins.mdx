Umbra also styles menus, EPG views, timers, text input and many plugin screens. Shared elements follow its appearance settings. The functions and data still belong to each plugin.

The illustrated TMDb detail page provides description, cover and metadata. **TMDb is a separately installed plugin, not the e2MDB database.** The two names should not be treated as interchangeable.

## What the Umbra settings do not edit

The Umbra plugin is not an editor for every widget in every plugin. Mini-TV areas, compact dialogs and adapted lists may be fixed properties of a screen. There is no general “mini TV everywhere” switch.

Covered families include AutoTimer, IMDb/TMDb, FileCommander, MediaPlayer, PicturePlayer, EMC and many adapted Metrix plugin templates. Feed versions may use different screen names. The handbook does not imply complete visual validation of all possible plugin versions.

Long-press shortcuts, for example those opening additional EPG views, follow your OpenATV key assignments. Umbra does not redefine the remote control. Colour buttons can perform different actions in different screens; use their current labels.

For a screen that does not fit, report the plugin name and version, screen title, steps to open it, OSD resolution and a screenshot. See [reporting a problem](../../../hilfe/fehler-melden/).
