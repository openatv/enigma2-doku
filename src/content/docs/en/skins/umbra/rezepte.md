## Return to the selected pack

**Yellow — Pack values** resets all style overrides after confirmation, including sections that are currently hidden. Press Green to apply. To reset one option only, choose From style pack or clear its RGB field. Resolution and local weather data are not style overrides.

## A quiet appearance for films

Choose **Umbra Cinema**. Set status icons to Active only or Off if desired. Tuner and encryption information can stay off. Cinema does not automatically hide status icons.

## Better readability

Choose **Umbra Klar**, or set text to **105%** and menu width to **Wide**. Check long channel names and plugin texts. With custom colours, start by checking contrast between main text and the selection surface. Reduce text size if content does not fit.

## More channels or more programme detail

For more entries, use a normal list view with compact rows. For more information per channel, use extended rows or columns. The original HD gallery shows up to 15 tiles and the HD columns view five tall columns. Current FHD/WQHD profiles have different capacities; see [resolution](../aufloesung/).

## Combine artwork and weather

With e2MDB active, select Cover or Panorama for the Infobar. Independently enable the 5-day weather forecast and enter location and coordinates. Hamburg's example input is **9.99302,53.55073**. Save and open the full Infobar.

## Judge an unmodified pack

Select the pack, press Yellow and confirm resetting overrides. Check resolution separately, then press Green. Otherwise an RGB colour set earlier may change your impression of the new pack.

The current pack, personal override and local setting are distinct layers. Before resetting everything, identify which layer controls the unwanted result.
