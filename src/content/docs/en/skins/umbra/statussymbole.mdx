## Interpret the values

SNR describes signal quality, AGC is a driver-reported level value and BER is the reported bit-error rate. Missing or substituted values depend on the device. Umbra does not calculate these measurements. Free-to-air services have no active decryption details.

HD/UHD, HbbTV, audio and other icons follow the current service information. Making an icon visible does not enable the underlying feature. Likewise, hiding a status symbol does not disable the service.

The full Infobar's diagnostic row and the native second ECM page are separate views. Start with only the information you need and add diagnostic details when investigating a reception issue.
