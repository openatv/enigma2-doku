Open **Colours (Farben)**. A palette provides matching background, surface, selection and text colours. Progress colour can be selected independently.

| --- | --- |
| Graphit | Graphite; grey with a cool blue-green tint. |
| Mitternacht | Midnight; dark blue. |

| Smaragd | Emerald; dark green. |
| Petrol | Blue-green. |
| Bordeaux | Burgundy tones. |
| Bernstein | Amber; warm brown-gold tones. |

The unchanged illustration uses **Sendername / Aktuelle Sendung** for channel name/current programme and **Haupttext / Nebentext** for main/secondary text. Every row uses the same illustrative content, so the colours can be compared directly.

| Option | Choices and effect |
| --- | --- |
| Palette (Farbwelt) | Graphite, Midnight, Carbon, Emerald, Petrol, Bordeaux, Amber. Changes the coordinated base colours; RGB overrides can replace individual roles. |
| Progress colour (Fortschrittsfarbe) | Skin colour, Cyan, Blue, Green, Red, Gold, White. Changes supported progress/accent indicators. Skin colour uses the palette default. A custom Accent RGB value takes precedence. |

A palette is part of a style pack. Selecting a palette alone does not replace all other pack settings. To evaluate a pack's original appearance, also review personal overrides.
