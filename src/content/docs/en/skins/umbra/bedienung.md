The first three rows belong to every section: **Style pack (Stilpaket)**, **Section (Bereich)** and **OSD resolution**. They can scroll out of view. Section filters the options into Colours, Layout, Infobar and Channel list. Switching sections retains all unsaved changes.

| Control | What happens |
| --- | --- |
| Up / Down | Select a setting. |
| Left / Right | Cycle through the available values. Edit text fields with the normal OpenATV input method. |
| Green — Save | Save all changes and apply Umbra again, including changes in other sections. |
| Red / EXIT — Cancel | Discard unsaved changes in every section. |
| Yellow — Pack values (Paketwerte) | After confirmation, reset all personal style overrides. Green applies the new state. |
| Blue — Save style (Stil speichern) | Export the currently effective appearance as a personal pack. The exported file remains even if you cancel afterwards. |

## A first adjustment

1. Choose **Umbra Graphit** and initially leave the resolution unchanged.
2. Open Colours and choose another progress colour.
3. Press Green and wait until the applying message disappears.
4. Open the Infobar and channel list. Return to Umbra to make further adjustments.

With a compatible OpenATV version, live reloading usually avoids a GUI restart. Applying a style can take considerably longer than a few seconds on a receiver. Wait for completion instead of repeatedly saving. If live reloading is unavailable or incomplete, Umbra offers a GUI restart.

The installed Umbra settings interface uses German labels even when Enigma2 is switched to English. This handbook translates the controls and explains the original labels; screenshots preserve the real interface.
