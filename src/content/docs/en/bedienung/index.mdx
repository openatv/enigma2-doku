**Menu → Setup → Usage & GUI** groups everyday controls, on-screen information and input devices. These are the 13 fixed entries in the reviewed OpenATV menu. Plugins can add further entries. Hardware-specific entries appear only when the receiver exposes that capability.

The existing detailed guides are linked below. The **settings reference** already contains the labels, original help, configuration keys and visibility conditions extracted from each setup. It complements the practical guides.

## A menu entry or option is missing

Select **Customize System Settings → Settings mode → Expert** when needed. Expert reveals additional settings; it does not add missing hardware. It cannot provide an absent display, PiP decoder or configurable remote code. Sub-options may also depend on another switch, list style or skin. Check for [hidden menu entries](../erste-schritte/menue-anpassen/) too.

Reference counts describe the source catalogue, not the number of rows visible simultaneously on every receiver. The GUI skin field, present with two different restart conditions, is counted once.

## Find the right topic

- **Cannot find a setting:** search its visible label, English label or short key, such as `screenSaverMode`, `Picon search mode` or `key repeat`.
- **MENU inside an open menu:** opens [OSD settings](../erste-schritte/menue-anpassen/). MENU has separate actions in a channel list, plugin or setup dialog.
- **Audio/subtitle language:** use [automatic language selection](../bild-ton/tonspuren/) rather than menu language.
- **Clipped picture or incorrect HDMI resolution:** see [OSD calibration](../bild-ton/bildanpassung/) or [video output](../bild-ton/video/).
- **Style your skin:** see [MetrixHD](../skins/metrixhd/) or [Umbra](../skins/umbra/).

[Sources and verification](./quellen/) explain the basis and the limits of the test receiver.
